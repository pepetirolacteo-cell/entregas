Cum Instalezi Preseturile

  1. Desktop (Lightroom Classic): Mergi la Develop → Presets → Import Presets → selectează fișierele .xmp
  2. Desktop (Lightroom CC): Mergi la Edit → Presets → ⋯ → Import Presets → selectează fișierele .xmp
  3. Mobil (Lightroom Mobile): Deschide fișierele .dng în Lightroom → copiază setările → salvează ca preset
  4. Photoshop (Camera Raw): Mergi la Presets Panel → ⋯ → Import Profiles & Presets → selectează fișierele .xmp
